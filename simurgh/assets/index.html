Panel access

          

          

          
One-time login link

          

            

            
          

          

          
The link signs in once and then dies. Useful to hand the panel to someone you trust without telling them the password, and never shows the password in a URL.

        

        

          
How it is guarded

          
    
            
  • Session cookie + Basic auth; five wrong passwords from an address lock it out for 300 s.
    • 
            
  • Strict Content-Security-Policy: no external script, style, image or font can load.
    • 
            
  • Tokens are masked in the API, and the panel only edits a safe subset of the config.
    • 
            
  • The panel is read-mostly and never sits in the data path: the tunnel keeps forwarding if it dies.
