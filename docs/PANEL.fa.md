# پنل وب

[English](PANEL.md) · **فارسی**

پنل، صفحه‌ای است که تونل دربارهٔ خودش سرو می‌کند: نقشهٔ دو سر تونل، عددهای پشتشان
و دکمه‌هایی که اپراتور ساعت سه صبح سراغ‌شان می‌رود. پنل جزئی از بسته است — یک فایل
پایتون (`simurgh/panel.py`)، یک فایل داده (`simurgh/layout.py`)، یک جدول رشته
(`simurgh/panel_i18n.py`) و چهار asset در `simurgh/assets/`. نه مرحلهٔ build دارد،
نه فریم‌ورک، نه CDN و نه وابستگی جاوااسکریپتی: هیچ‌کدام از چیزهایی که پنل نشان
می‌دهد برای بار شدن به اینترنت نیاز ندارد.

## باز کردن پنل

```bash
simurgh web                       # فقط پنل، کنار نود در حال اجرا
simurgh web --link                # …و یک لینک ورود یک‌بارمصرف روی خروجی
simurgh web --port 9000 --host 127.0.0.1
```

راه معمول، سرویس است: `simurgh start` هم نود و هم پنل را اجرا می‌کند و پورت پنل
از `panel_port` در `relay.toml` می‌آید (پیش‌فرض `8787`). روی اگزیت هم اگر از منو
اجرا کنید، پنل روی همان پورت پنل رله سرو می‌شود.

| راه ورود | چطور |
|---|---|
| پرسش رمز | `http://<ip>:8787` — HTTP Basic، مناسب اسکریپت و `curl` |
| لینک یک‌کلیکی | `http://<ip>:8787/?k=رمز-پنل` — برای مرورگری که رمز ذخیره نکرده |
| فرم ورود | `http://<ip>:8787/login` — فرم واقعی، `EN / فا` |
| لینک یک‌بارمصرف | `simurgh web --link` یا صفحهٔ امنیت: یک‌بار، ۱۰ دقیقه |

> اگر سرور از اینترنت قابل دسترسی است، پنل را پشت فایروال یا تونل SSH بگذارید.
> پنل احراز هویت دارد و سخت‌شده است، ولی همچنان یک control plane است:
> `ssh -L 8787:127.0.0.1:8787 root@server` و در مرورگر
> `http://127.0.0.1:8787`.

## نقشه

داشبورد تونل را به شکل همان پرنده‌ای می‌کشد که نامش از اوست:

```
        رله (بال چپ)                   بدنهٔ تونل                    اگزیت (بال راست)
   ┌─────────────────┐   ╔═════════════════════════╗   ┌─────────────────┐
   │ کشور · نام      │   ║  tls :443  · rtt 12 ms  ║   │ کشور · نام      │
   │ آپ‌تایم · کانکشن │   ║  استخر: ۲ اگزیت، ۱ زنده ║   │ لیسن · تونل‌ها  │
   └─────────────────┘   ╚═════════════════════════╝   └─────────────────┘
            ╲                    پرهای دم                          ╱
             ╲  443 ●── کوتا ۵۰٪ ─▶ 127.0.0.1:8443  ↓ 2.1 Mb/s   ╱
```

* **بال‌ها** — نام هر سر، آپ‌تایم، تعداد کانکشن و آخرین خطا. هر بالی که طرفش
  پایین باشد کم‌رنگ می‌شود و دلیلش روی hover می‌آید.
* **بدنه** — کریر فعال، پورت، RTT و اینکه استخر چند اندپوینت می‌شناسد و چند
  تا زنده است. اندپوینت جانشین حلقهٔ توخالی است و فعالِ پرشده؛ hover وضعیت
  جانشینی هرکدام را نشان می‌دهد.
* **پرهای دم** — یکی برای هر مپینگ: پروتکل، پورت شنیدن، مقصد، حلقهٔ کوتا، نرخ
  لحظه‌ای و اسپارک‌لاین چند دقیقهٔ اخیر. پری که ترافیک از آن رد شود روشن می‌شود.
* **نمودار** — مجموع ورودی/خروجی نیم ساعت گذشته، از تاریخچهٔ خود پنل
  (`layout.History`؛ نمونه هر ۲ ثانیه، ارسال با دقت ۱۰ ثانیه).

همهٔ چیزهایی که روی صفحه می‌بینید از یک درخواست می‌آید: `GET /api/layout` هر دو
ثانیه (و هرگز وقتی تب مرورگر مخفی است).

## نماها

| نما | توضیح |
|---|---|
| داشبورد | نقشه، کارت‌ها، نمودار و استخر |
| جفت‌سازی | فقط تا وقتی رله جفت نشده: لینک راه‌اندازی اگزیت را بچسبانید تا نود در حال اجرا همان‌جا آن را بپذیرد |
| پورت‌ها | افزودن/حذف/خاموش‌روشن/تغییر مقصد مپینگ‌ها؛ تغییر در کانفیگ نوشته و بدون ری‌استارت روی نود اعمال می‌شود |
| ویزارد | پیش‌نمایش ← اعمال ← بازگردانی برای تونل تازه؛ پایین توضیح داده شده |
| تست سرعت | دانلود/آپلود تا اگزیت، نمرهٔ تأخیر، تاریخچهٔ همین نشست در مرورگر |
| گواهی‌ها | همان خروجی `simurgh cert status` با روز باقی‌مانده و اثر انگشت |
| لاگ‌ها | دم لاگ نود، با فیلتر و بروزرسانی خودکار |
| امنیت | نشست‌ها، قفل‌شدن‌ها، ورودهای ناموفق، لینک‌های یک‌بارمصرف و قواعد سخت‌سازی |
| تنظیمات | زیرمجموعهٔ قابل‌ویرایش کانفیگ، موتور فعال و توکن تونل |
| ابزارها | ری‌استارت/توقف/شروع/اتصال دوباره، خروجی کانفیگ، دانلود لاگ، `/metrics` و `/healthz`، بررسی به‌روزرسانی |

## جفت کردن رله‌ای که اول نصب شده

`install.sh` روی سرور ایران هیچ چیزی نمی‌پرسد: `relay.toml` را با
`unpaired = true` می‌نویسد و پنل را بالا می‌آورد. تا وقتی سرور جفت نشده،
داشبورد همین را می‌گوید و یک صفحهٔ **جفت‌سازی** در نوار کنار ظاهر می‌شود (همان
لحظه‌ای که جفت شود غیب می‌شود). صفحه سه قدم و یک فیلد است:

1. روی اگزیت، `simurgh link` خطی چاپ می‌کند که با `simurgh://` شروع می‌شود؛
2. همان را در **لینک راه‌اندازی** بچسبانید؛
3. **جفت کن** را بزنید.

`POST /api/pair {"link": "simurgh://…"}` همان چیزی را می‌گیرد که `simurgh join`
می‌گیرد، کانفیگ را می‌نویسد (نسخهٔ قبلی در `relay.toml.bak-pair` می‌ماند) و در
موتور پایتون بدون ری‌استارت اعمالش می‌کند — تونل همان‌جا شروع به dial می‌کند.
هر چیزی که نصب انتخاب کرده بود می‌ماند: پورت پنل، موتور، محدودیت‌ها و پورت‌هایی
که قبلاً اضافه کرده‌اید. این اندپوینت لینکِ مخصوص اگزیت را رد می‌کند، جفت‌سازی
دوباره را هم (با `simurgh join --force`)، و رله‌ای که جفت‌نشده نیست.

## ویزارد

ساختن دستی تونل یعنی درست درآوردن کریر، پورت، مسیر، split و اولین مپینگ در هر دو
سر. ویزارد این را به نقشه‌ای تبدیل می‌کند که پیش از هر نوشتنی می‌خوانید:

1. **پیش‌نمایش** — `POST /api/wizard {"step": "preview", "plan": {...}}` دیف را
   نسبت به کانفیگ فعلی برمی‌گرداند (`[exit] carrier tls -> wss`) و هیچ نمی‌نویسد.
   نقشهٔ رد‌شده دلیلش را می‌گوید: کریر ناشناس، پورتی بیرون ۱ تا ۶۵۵۳۵، مپینگی که
   `listen:target` نیست، یا split‌ای که عدد نیست.
2. **اعمال** — فایل فعلی در `<config>.bak-wizard` کپی می‌شود، نقشه نوشته می‌شود و
   نود در حال اجرا بدون ری‌استارت بازتنظیم می‌شود.
3. **بازگردانی** — بکاپ برمی‌گردد و دوباره بارگذاری می‌شود. یک کلیک، و فایل قبلی
   بعد از آن هم سر جایش می‌ماند.

نقشه عمداً کوچک است: `carrier` (tls، wss، raw، plain، udp)، `port`، `host`،
`path`، `split` و `mapping` (`listen:target`). بقیهٔ چیزها در فایل کانفیگ می‌مانند،
همان‌جا که با دست هم می‌توانید ویرایش کنید.

## تم، زبان و گوشی

* `night` پیش‌فرض است و `dawn` تم روشن. این انتخاب (مثل زبان) در هر مرورگر ذخیره
  می‌شود (`localStorage`).
* انگلیسی و فارسی با هم می‌آیند (`simurgh/panel_i18n.py`)، برای فارسی `dir` به
  `rtl` می‌رود و اگر این دو جدول از هم دور بیفتند یک تستfail می‌شود.
* زیر ۷۲۰ پیکسل سایدبار به نوار پایین تبدیل می‌شود، نقشه بال‌ها را روی بدنه
  می‌چیند و جدول‌ها افقی اسکرول می‌شوند — پنل روی گوشی کار می‌کند، همان‌جایی که
  بیشتر این سرورها اول از همه چک می‌شوند.
* به‌شکل وب‌اپ هم نصب می‌شود: `/manifest.webmanifest` و آیکن.

## چه چیزی امنش نگه می‌دارد

| قاعده | چرا |
|---|---|
| CSP سخت (`default-src 'none'`)، بدون اسکریپت یا استایل inline | صفحه‌ای که چیزی از بیرون نمی‌کشد، نمی‌تواند وادار به کشیدن چیزی شود |
| asset‌ها با نام از بسته سرو می‌شوند | `read_asset` هر چیزی که مسیر داشته باشد را رد می‌کند؛ traversal ممکن نیست |
| `Cache-Control: no-store` روی هر پاسخ API و روی کد | مرورگر هیچ‌وقت عدد یا صفحهٔ کهنه نشان نمی‌دهد |
| `X-Frame-Options: DENY` | پنل را نمی‌توان در صفحهٔ فیشینگ قاب گرفت |
| پنج ورود ناموفق از یک آدرس ← قفل ۳۰۰ ثانیه‌ای (`429`) | جلوگیری از brute force، هم روی پنل و هم روی `/metrics` |
| لینک‌های یک‌بارمصرف هش‌شده، یک‌بار قابل‌استفاده، TTL ده‌دقیقه‌ای، حداکثر ۵ لینک باز | لینک لو‌رفته بی‌ارزش است؛ `revoke` همه را دور می‌ریزد |
| توکن‌ها هرجا چاپ شوند ماسک می‌شوند | لاگ و پنل هیچ‌وقت رمز چاپ نمی‌کنند |
| پنل هرگز در مسیر داده نیست | می‌توان متوقف، ری‌استارت یا خرابش کرد بدون آنکه ترافیک آسیب ببیند |

## API

هر کاری که پنل می‌کند یکی از این‌هاست؛ همه احراز هویت دارند (Basic auth یا کوکی
نشستی که ورود می‌دهد):

| متد | مسیر | کار |
|---|---|---|
| GET | `/` | صفحهٔ shell (رشته‌ها در یک بلوک دادهٔ JSON می‌آیند) |
| GET | `/app.css`، `/app.js`، `/login.js`، `/favicon.ico`، `/assets/<name>`، `/manifest.webmanifest` | asset‌ها، مستقیم از بسته |
| GET | `/api/status` | وضعیت نود + پنل (پاسخ کوچک) |
| GET | `/api/layout` | نقشه، کارت‌ها، نمودار و نرخ‌ها (پاسخ بزرگ) |
| GET | `/api/config` | کانفیگ قابل‌ویرایش |
| POST | `/api/config` | نوشتن آن |
| POST | `/api/mapping` | افزودن/حذف/خاموش‌روشن مپینگ، اعمال زنده |
| POST | `/api/speedtest` | اجرای تست سرعت |
| POST | `/api/action` | ری‌استارت/توقف/شروع/اتصال دوباره/بارگذاری مجدد |
| POST | `/api/tune` | اعمال پروفایل کارایی (`gaming`، `balanced`، `speed`) |
| POST | `/api/pair` | جفت کردن رلهٔ جفت‌نشده با لینک راه‌اندازی اگزیت |
| POST | `/api/wizard` | پیش‌نمایش/اعمال/بازگردانی نقشهٔ تونل |
| POST | `/api/login-token` | ساخت لینک ورود یک‌بارمصرف |
| POST | `/api/join` | payload نصب یک‌خطی برای رلهٔ تازه |
| GET | `/api/update` | یک بار پرسیدن از گیت‌هاب که نسخهٔ تازه‌تری هست یا نه |
| GET | `/api/logs`، `/api/security` | دم لاگ و شمارنده‌های نگهبان |
| GET | `/login`، `POST /login`، `GET /logout` | فرم، پاسخ فرم و خداحافظی |
| GET | `/metrics` | متن Prometheus برای همان اعداد (`simurgh_listen_*`، `simurgh_panel_*`، …) |
| GET | `/healthz` | زنده‌بودن، بدون احراز هویت، برای watchdog |

اگر می‌خواهید فرانت‌اند خودتان را بنویسید، همان `/api/layout` را بخوانید: JSON است،
همان داده‌ای است که نقشهٔ همراه پروژه می‌کشد، و `simurgh/layout.py` تمام لایهٔ
ترجمه بین آن و `status()` نود است.

## نوشتن روی آن

پنل دوست CLI است، نه جانشین آن: هر نوشتنی از همان `config.save_*` رد می‌شود که
CLI استفاده می‌کند، با همان اعتبارسنجی. اگر اصلاً پنل را نمی‌خواهید، `simurgh relay`
با `panel_port = 0` نود را بدون هیچ صفحه‌ای اجرا می‌کند و CLI دقیقاً مثل قبل کار
می‌کند.
