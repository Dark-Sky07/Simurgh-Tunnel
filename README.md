# سیمورغ تونل (Simurgh Tunnel) — نسخهٔ ۲

<div dir="rtl">

**تونل شفاف و نامرئی بین سرور ایران و سرورهای خارج.**

سیمورغ یک «فورواردر پورت» هوشمند است: ترافیک کاربران را از سرور ایران می‌گیرد و
از داخل یک تونل تک‌اتصالی و استتارشده به سرور خارج می‌رساند. کاربر **همان کانفیگ
قبلی‌اش را نگه می‌دارد** و فقط آدرس سرور را از خارجی به ایرانی تغییر می‌دهد؛
هیچ چیزی در پنل (3x-ui / OMEGA / …) عوض نمی‌شود.

مخصوص شرایط ایران طراحی شده: فیلترینگ هوشمند (DPI)، ای‌پی‌های فیلترشده،
پینگ بالا، سرور کم‌رم، و نصبی که باید در دو دقیقه تمام شود.

</div>

## چرا سیمورغ؟

| نیاز | کاری که سیمورغ می‌کند |
|---|---|
| IP و دامنهٔ سرور خارج فیلتر نشود | کاربران فقط با IP **سرور ایران** کار می‌کنند؛ آدرس خارجی هیچ‌وقت در کانفیگ کاربران دیده نمی‌شود. |
| DPI تشخیص نده | تونل یک اتصال TLS واقعی است: گواهی معتبر، دامنهٔ واقعی و **سایت طعمه**؛ اگر کسی بدون توکن وصل شود، یک وب‌سایت معمولی می‌بیند. |
| سرعت و کیفیت | یک اتصال TCP برای همهٔ کاربران (multiplexing)، بدون رمزگذاری دوبارهٔ ترافیک VPN، پنجرهٔ اعتبار (credit) برای کنترل حافظه، صفر کپی اضافه. |
| نصب آسان | یک فرمان: `install.sh` — نصب، تنظیم، سرویس systemd، پنل. |
| منوی متنی + پنل وب | منوی مدیریت کاملاً انگلیسی (`simurgh menu`) و پنل وب **دوزبانه (انگلیسی/فارسی)** با نمودار سرعت زنده. |
| کم‌مصرف | هیچ وابستگی سنگینی ندارد (نه Node، نه Go، نه دیتابیس)؛ رم مصرفی چند مگابایت ثابت است. |

## معماری

```
کاربر (v2ray/xray/…)
      │  همان کانفیگ قبلی، فقط آدرس = سرور ایران
      ▼
┌────────────────────────────┐
│  سرور ایران — رله (Relay)   │   پنل وب دوزبانه + منوی متنی + پورت‌های کاربران
│  :443  :2053  :2083 …      │
└─────────────┬──────────────┘
              │  یک تونل استتارشده و چندگانه (TLS + هدر احراز هویت + سایت طعمه)
              ▼
┌────────────────────────────┐
│  سرور خارج — اگزیت (Exit)    │   ترافیک را به پنل/سرویس محلی خودش تحویل می‌دهد
│  127.0.0.1:پنل             │
└────────────────────────────┘
```

هر پورت روی رله به یک پورت روی سرور خارج وصل می‌شود (`simurgh mapping add 443 443`).
چند سرور خارج هم پشتیبانی می‌شود: در فایل رله بخش `[[pool]]` را پر کنید تا در
قطعی سرور اصلی، خودکار روی سرور بعدی سوئیچ کند.

## نصب یک‌فرمانی

**۱) روی سرور خارج (Exit):**

```bash
curl -fsSL https://raw.githubusercontent.com/Dark-Sky07/Simurgh-Tunnel/main/install.sh | sudo bash /dev/stdin --role exit --name omega-de
```

یا از مخزن:

```bash
sudo bash install.sh --role exit --name omega-de --listen 443,2053,2083
```

نصب‌کننده خودش پایتون/ابزارها را نصب می‌کند، گواهی می‌سازد، سرویس systemd
می‌سازد و در پایان **لینک اتصال رله** را چاپ می‌کند:

```
✔ نصب کامل شد.
  لینک اتصال رله: simurgh://203.0.113.9:8787/setup?u=admin&p=…#omega-de
```

**۲) روی سرور ایران (Relay):**

```bash
sudo bash install.sh --role relay --exit 203.0.113.9:443
```

اگر لینک اتصال را دارید، ساده‌تر:

```bash
sudo simurgh join 'simurgh://203.0.113.9:8787/setup?u=admin&p=…#omega-de'
sudo simurgh mapping add 443 443 --name panel
sudo simurgh restart
```

> لینک اتصال حاوی توکن است؛ آن را محرمانه نگه دارید.

**۳) کاربران:** فقط آدرس سرور را در کانفیگ از سرور خارجی به IP سرور ایران
تغییر دهید. تمام.

## دستورهای پرکاربرد

```bash
simurgh menu                       # منوی متنی انگلیسی (پیشنهادی برای شروع)
simurgh status                     # وضعیت تونل، ترافیک، پینگ
simurgh mapping add 443 443        # پورت ۴۴۳ ایران → پورت ۴۴۳ سرور خارج
simurgh mapping list
simurgh speedtest                  # سرعت واقعی از داخل تونل
simurgh logs -f                    # لاگ زنده
simurgh doctor                     # عیب‌یابی خودکار
simurgh link --show                # لینک اتصال برای رله جدید (روی سرور خارج)
simurgh start | stop | restart     # کنترل سرویس (systemd)
simurgh uninstall --purge          # حذف کامل
simurgh web                        # فقط پنل وب
```

## پنل وب (دوزبانه)

آدرس: `http://<IP-سرور-ایران>:8787` — کاربر و رمز در اولین اجرا ساخته و در
`/etc/simurgh/state.json` ذخیره می‌شود (`simurgh status` هم نشان می‌دهد).

زبان پنل با دکمهٔ **EN / فا** در بالای صفحه عوض می‌شود؛ انتخاب هر زبان در مرورگر
ذخیره می‌شود و چیدمان (راست‌به‌چپ/چپ‌به‌راست) خودکار تغییر می‌کند. بار اول بر اساس
زبان مرورگر انتخاب می‌شود. **بقیهٔ بخش‌های سرور (منوی متنی، CLI و نصاب) کاملاً
انگلیسی هستند.**

**ورود یک‌کلیکی:** به‌جای پنجرهٔ نام‌کاربری، می‌توانید از لینک
`http://<IP>:8787/?k=<رمز-پنل>` استفاده کنید؛ یک کوکی نشست ساخته می‌شود و
دیگر رمز پرسیده نمی‌شود.

امکانات: وضعیت زندهٔ تونل و پینگ، نمودار سرعت دانلود/آپلود، افزودن/حذف/خاموش
کردن پورت‌ها **بدون ری‌استارت**، تست سرعت، ری‌استارت سرویس، لاگ زنده و لینک
اتصال رله. همه‌ی صفحه‌ها آفلاین کار می‌کنند (هیچ CDN یا فونت خارجی لازم نیست).

## حامل‌ها (نوع تونل)

| حامل | مناسب چه وقت | چه چیزی به چشم DPI می‌آید |
|---|---|---|
| `tls` (پیش‌فرض) | حالت معمول | یک وب‌سرور واقعی با گواهی، دامنه و سایت طعمه |
| `wss` | وقتی فقط WebSocket مجاز است | همان TLS + ارتقای WebSocket با مسیر دلخواه |
| `raw` | وقتی TLS مشکوک است | نویز تصادفی + تبادل کلید X25519 و رمزنگاری AEAD |
| `plain` | بین دو سرور مطمئن/داخلی | TCP خالص با هدر احراز هویت |

تنظیمات پیشرفته در `/etc/simurgh/exit.toml` و `/etc/simurgh/relay.toml` است؛
همه‌چیز توضیح‌دار و ساده.

## امنیت

* توکن مشترک با HMAC-SHA256 و بازهٔ زمانی ±۳ دقیقه + کش ضدتکرار (جلوگیری از replay).
* اتصال بدون توکن یا با توکن غلط → **سایت طعمه** (پاسخ ۲۰۰ nginx) نه خطا.
* گواهی خودامضا برای سرور خارج، و **پین اثر انگشت** (SHA-256) در سرور ایران؛
  با دامنهٔ واقعی (Let’s Encrypt) هم کار می‌کند.
* هیچ‌وقت لازم نیست گواهی معتبر روی سرور ایران داشته باشید؛ کاربران TLS خودشان را
  تا انتها نگه می‌دارند (تونل کاملاً شفاف است).



## عیب‌یابی سریع

| نشانه | راه‌حل |
|---|---|
| پنل باز نمی‌شود | پورت پنل (`8787`) را در فایروال باز کنید: `ufw allow 8787` |
| تونل وصل نمی‌شود | `simurgh doctor` — فایروال سرور خارج را باز کنید و توکن دو طرف را چک کنید (یکسان باشد). |
| یک پورت کار نمی‌کند | `simurgh mapping list` و مطمئن شوید سرویس روی `127.0.0.1:پورت` سرور خارج بالاست. |
| سرعت کم است | `simurgh speedtest`؛ اگر تونل سریع است، مشکل از سمت سرور خارج/شبکه کاربر است. |
| همه‌چیز را برمی‌گردانم | `sudo simurgh uninstall --purge` |

سرویس‌ها: `systemctl status simurgh-exit` و `systemctl status simurgh-relay`.

## نصب دستی (بدون اسکریپت)

```bash
git clone https://github.com/Dark-Sky07/Simurgh-Tunnel.git
cd Simurgh-Tunnel
python3 -m venv .venv && . .venv/bin/activate
pip install -e '.[secure]'
simurgh init --role exit          # یا: --role relay --exit HOST:PORT
simurgh exit                      # اجرای دستی
```
